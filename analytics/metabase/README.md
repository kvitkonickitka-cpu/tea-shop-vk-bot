# Дашборды Metabase как код

## «Пульс»: `dash_build.py` (с 21.10.2026)

Главный дашборд — в коллекции «Дашборды», собирает `dash_build.py`. «Пульс» —
главная страница Metabase:

- **каждый день** — вкладки «Сегодня», «Деньги», «Продажи», «Товар»: один экран — один
  вопрос, ответ в верхнем ряду;
- **раз в неделю и в конце месяца** — следом за «Товаром» вкладки «Ввод данных» (формы),
  «Сверки», «Отчёты», «Вводные», «Каталог» (каталог бота, `shop.catalog`).

До 24.10.2026 служебные вкладки были отдельным дашбордом «Служебное» (№12); владельцу
удобнее один экран, и сборка переносит их в «Пульс», а «Служебное» отправляет в архив.

Все числа — из представлений `fin` (миграция 009, `analytics/fin/README.md`); формы —
через подключение «Финмодель (ввод)», функциями `fin_build.py`. Скрипт ставит
глобальные форматы (20.10.2026, 14:37, «32 731 ₽», «12,5 %»), собирает вопросы,
модели и формы заново в «Пульс и Служебное — вопросы» и обновляет «Пульс» на месте.
Ссылки не меняются, прежняя подколлекция уходит в архив. Карточки, у которых пока
нет данных (продажи до старта пилота), скрыты.

```bash
scp analytics/metabase/{mbapi,fin_build,dash_build}.py root@<ВМ>:/root/mb/
ssh root@<ВМ> 'cd /root/mb && MB_FIN_PW="$(cat /etc/teashop/metabase_fin_password)" python3 dash_build.py'
```

«Сводка» (`build.py`) и «Финансы» (`fin_build.py`) после переезда — в архиве. Оба
скрипта останавливаются, если «Пульс» уже есть: `build.py` архивировал бы коллекцию
«Дашборды» вместе с новыми дашбордами.


`build.py` собирает в Metabase коллекцию «Дашборды» с одним дашбордом «Сводка»:
вкладка «Обзор» (главное на одном экране), «Деньги» (витрины `finance`, как
было в DataLens), «Воронка», «Заказы», «Удержание», «Ассортимент» (витрины
`analytics`), «Себестоимость и маржа» (справочники из Google Таблицы:
`v_ref_*`, `v_order_margin`, `v_order_item_margin`). Один вопрос может стоять на нескольких вкладках — это та же
карточка, данные не копируются. Все вопросы — SQL с фильтрами
«Даты» и «Период»; после сборки каждый вопрос выполняется, ошибки печатаются.

Повторный запуск собирает вопросы заново в новой коллекции «Дашборды», а сам
дашборд «Сводка» **обновляет на месте**: id и ссылка не меняются (с 18.10.2026 —
`https://stats.teapotwice.ru/dashboard/5`). Прежняя коллекция с прежними вопросами
уходит в архив. **Ручные правки вопросов и раскладки пропадут** — правьте здесь,
потом запускайте.

Столбчатым спискам (`row`) ставится `graph.max_categories_enabled: false`, иначе
Metabase сворачивает хвост в «Other». И карточке со списком нужна высота: строки,
не влезшие по высоте, он сворачивает всё равно.

Запуск — на ВМ, ключ API Metabase читается из `/etc/teashop/metabase_api_key`
(кладёт владелец: `/root/metabase_set_key.sh`, ключ на экран не выводится):

```bash
scp analytics/metabase/*.py root@<ВМ>:/root/mb/
ssh root@<ВМ> 'cd /root/mb && python3 build.py && python3 verify.py <id дашборда>'
```

id полей с датой (`F` в `build.py`) и id базы (`DB`) — из
`GET /api/database/<id>/metadata`; сменятся, если подключение в Metabase
пересоздать. Поля новых представлений (вкладка «Себестоимость и маржа»)
`build.py` находит сам по имени (`sync_fields`): сначала просит Metabase
синхронизировать схему и ждёт, пока они появятся, — поэтому запускать его
только после деплоя бота с этими представлениями. Не дождался — останавливается
до того, как прежняя коллекция уйдёт в архив.

## Финансы: `fin_build.py`

Коллекция «Финансы» — дашборд «Финансы» (`/dashboard/6`) с вкладками «Деньги»,
«Юнитка», «Реклама и CAC», «Склад и коды», «Ввод данных» и формы ввода (Actions).
Схема и роль — `analytics/fin/README.md`.

- **Подключение для форм** — «Финмодель (ввод)», роль `metabase_fin`.
  Видит только схему `fin`, действия включены. Вопросы дашбордов идут через
  прежнее подключение (`DB = 2`, `metabase_ro`).
- **Повторный запуск**: вопросы, модели и формы собираются заново в
  «Финансы — вопросы», прежняя подколлекция уходит в архив. Дашборд
  обновляется на месте. «Сводку» скрипт не трогает.

```bash
scp analytics/metabase/mbapi.py analytics/metabase/fin_build.py root@<ВМ>:/root/mb/
ssh root@<ВМ> 'cd /root/mb && MB_FIN_PW="$(cat /etc/teashop/metabase_fin_password)" python3 fin_build.py'
```
