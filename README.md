# Два чайника: бот VK и процессы магазина

Бот на FastAPI принимает события VK, консультирует через OpenAI, оформляет
заказы серверными инструментами и передаёт вопросы менеджеру в Telegram.
Рабочий хостинг — Timeweb; OpenAI и Telegram доступны через прокси Aeza.

## Правила выпуска

Полный локальный pytest на отдельной PostgreSQL должен быть зелёным до коммита.
Затем PR и обязательные GitHub Actions, merge только при успехе. Деплой Timeweb
запускается вручную после успешных тестов main. После него проверяются точная
revision в `/health`, `database=ok`, контейнеры, свежие логи и основные функции.
При падении проверки дальнейший merge/деплой останавливается до исправления.

Ключи и `.env.bot` в репозиторий не попадают. Локальный Codex использует подписку
ChatGPT; серверный OpenAI API оплачивается отдельно. Исторические названия
`claude_client` и части финансовых витрин сохранены для совместимости.
