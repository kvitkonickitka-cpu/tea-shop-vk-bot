# Текущее состояние системы

Проверено 01.11.2026 чтением конфигурации рабочего контейнера, каталога,
наличия финансовых витрин и cron. Это снимок, а не вечные значения.
Рабочая ревизия приложения: `5e5d027553d9`, [выпуск демо](https://github.com/kvitkonickitka-cpu/tea-shop-vk-bot/pull/74).
Документация не меняет конфигурацию сервера. Перед новым выпуском сверять `/health`
и окружение; не переносить неподтверждённые числа из переписки в отчёты.

## Временное демо

[Описание и откат](investor-demo.md). Тестовый `P-TEST-100` («Те Гуань (тест)», 550 ₽)
уже существовал. Для всех новых сообщений доступен тестовый товар; в новом
контексте нет инструкции о закрытом магазине. Старую историю не удаляем.
Метки TEST_VK_IDS сохранены; новые/переоткрытые в демо заказы помечаются тестовыми.
В демо каталог ограничен только этим артикулом, вопросы о других позициях
не эскалируются. Просьбы о человеке и реальные проблемы заказа сохраняют
штатную передачу. При `false` обычные посетители снова не видят тестовый товар.

У тестового артикула на момент проверки нет сырья. Демо разрешает предложение
только `is_test && on_sale`, не создаёт фиктивный приход и сохраняет `stock_ok`.
Согласия, ЮKassa, эскалации и перевозчики настоящие. Получение счёта не требует
оплаты; сборка/отгрузка после оплаты ограничена фактическим сырьём и кодами.
Выключение демо не отменяет уже созданные платежи или отправления.

## Данные и ссылки

Перед моделью очищаются история, контекст и результаты инструментов. PII vault
зашифрован AES-GCM. Остаточные риски: необычные имена и ПДн на фотографиях.
`store=false` не следует трактовать как обещание отсутствия любой обработки данных.

На границе отправки Telegram ссылки на клиентские диалоги заменяются токенами
`https://stats.teapotwice.ru/secure-dialog/<token>`. Адрес VK раскрывается после
проверки действующей сессии активного администратора Metabase. Без сессии — вход
Google; при недоступном Metabase — отказ без раскрытия. Старые отправленные
карточки не переписаны. Смена PII-ключа затрагивает vault и старые ссылки.

## Аналитика и расходы

`analytics` — операционные витрины, `finance` — банковская выписка cashflow,
`fin` — финансовая модель. План, факт, синтетическое демо и неизвестное
различаются; тестовые заказы исключаются из коммерческих показателей, реальные
расходы тестов сохраняются. Взнос/пополнение API-баланса не равен расходу P&L.

На сервере отдельно подтверждены `fin.v_ai_billed_costs`,
`fin.v_openai_cost_reconciliation` и cron `teashop-openai-costs` на 17-й минуте
каждого часа. Официальный счёт и оценка токенов — разные показатели, не суммировать.
Загрузчик и последние финансовые доработки управляются финансовым контуром;
их исходники и генераторы ещё не полностью синхронизированы с main этого
репозитория. Наличие витрины на сервере не доказывает воспроизводимость её
пересборки из main. Не запускать старые генераторы поверх живых дашбордов без
сверки с текущими источниками. Декабрьский план от начислений API автоматически
не меняется. Полный Balance Sheet, денежный прогноз с запасами и межпериодный
подотчёт не объявлены завершёнными.
