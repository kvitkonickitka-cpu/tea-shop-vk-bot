# Временное публичное демо инвестору

`INVESTOR_DEMO_ENABLED=true` в окружении бота открывает существующие тестовые
артикулы всем собеседникам VK, без добавления их в TEST_VK_IDS. Демо по умолчанию
выключено (`false`); это не значение рабочего окружения. Реальные товары сохраняют свою доступность,
декларации, маркировку, согласия и проверки оформления. Инструменты не имитируются:
счёт, эскалации и последующие действия перевозчика идут в настоящие сервисы.
Не оплачивать счёт, если проверяется только получение ссылки.

Включать после локальных тестов, PR и зелёных проверок main; деплой по обычному
регламенту, затем /health с точной ревизией и database=ok. Перед включением
проверить `shop.catalog`: тестовый товар должен иметь is_test=true, on_sale=true,
цену и GTIN. В демо только у is_test=true наличие определяется on_sale,
без фиктивного прихода сырья. stock_ok сохраняет реальный статус; обычные товары
остаются под складским контролем. Не создавать дубликат уже существующего артикула.
На момент подготовки на сервере найден P-TEST-100, TEST ITEM 100G, 550 ₽.

Каталог в демо не содержит инструкции о неоткрытом магазине. Добавляется явное
указание модели использовать текущие тестовые товары и не повторять прежнюю
дату открытия из истории. Старую переписку не удаляем. Новые заказы и счета,
переоткрытые в демо, сохраняются is_test=true и с details.investor_demo=true;
после выключения остаются тестовыми. Коммерческая аналитика их исключает.
Статус клиента постоянно тестовым не делается.

На сервере у тестового артикула нет сырья по складу. Проверка до счёта доступна;
после оплаты резерв может выдать предупреждение о дефиците. Деморежим не создаёт
физический товар, коды маркировки или фиктивные партии и не гарантирует сборку.

Откат по просьбе владельца: установить INVESTOR_DEMO_ENABLED=false и пересоздать
bot через docker compose в deploy/timeweb. Код откатывать не требуется.
Проверить /health, обычному аккаунту тестовый товар недоступен, снова действует
сообщение о дате открытия. Уже оплаченные заказы, платежи и отправления не
отменяются автоматически: это отдельные реальные операции, их проверяет владелец.
Метка demo не изменяет юридические и финансовые последствия реального платежа.
