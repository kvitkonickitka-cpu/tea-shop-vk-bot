# Проверка маркировки на тестовых отправках

Автотесты (`tests/test_marking_*.py`, `test_packing.py`,
`test_settlement_receipt.py`) проверяют разбор кодов, проверки сборки, состав
закрывающего чека и чека возврата без настоящих ЮKassa и «Честного знака».
Этот список — то, что автотест проверить не может: печать, камера, касса и
кабинет «Честного знака». Проходить, когда есть заведённые карточки в
Национальном каталоге, коды из СУЗ, напечатанные этикетки и упаковка.

## Подготовка

- GTIN каждой позиции — в столбце «GTIN» таблицы каталога, тип — в столбце
  «Тип» (`пачка`, `сет` или `набор`). Проверить: `scripts/api.sh catalog/sheet`,
  в списке «бот продаёт» у каждого товара есть GTIN.
- Пул кодов загружен: `scripts/api.sh codes/import <выгрузка СУЗ>`, в ответе
  «ошибок: 0».
- Закрывающий чек включается флагом `SETTLEMENT_RECEIPT_ENABLED` — **только на
  время проверки и только с согласия владельца**. Его включение означает
  настоящий чек в ФНС. После проверки флаг выключить.
- Минимальная сумма заказа: самый дешёвый товар, доставка в ближайший пункт.

## 1. Печать этикеток и скан с телефона

**Сделать.** Напечатать на XP-365B этикетки 58×40 для пачки и для коробки
сета. Открыть страницу сборки по ссылке из карточки «💰 Оплачено» (или
`scripts/api.sh orders/<N>/pack-link`) на телефоне сборщика, при обычном
свете в помещении. Включить камеру, отсканировать пачку и коробку сета.

**Ожидаемо.** Каждый код принимается за 1–2 секунды, на странице «✓ <товар>:
1 из 1», без пометки «разделитель GS восстановлен». Если пометка есть —
принтер или шаблон этикетки теряют GS, это надо исправить в шаблоне печати.

**Где смотреть.** Страница сборки; в базе — `order_marking_codes.raw_code`
содержит символ 0x1D перед `93` (`scripts/api.sh`-ом не выводится — через
Metabase или psql на ВМ: `select position(chr(29) in raw_code) > 0 from
order_marking_codes order by id desc limit 5`).

## 2. QR «Как заваривать» не перехватывает скан

**Сделать.** Навести камеру на этикетку так, чтобы в кадре были оба кода — QR
и DataMatrix. Потом — только на QR.

**Ожидаемо.** С обоими кодами в кадре принимается DataMatrix. Один QR не даёт
никакой реакции: сканер настроен только на DataMatrix и QR не читает вовсе.

**Где смотреть.** Страница сборки: нет сообщения об ошибке на QR, счётчик не
растёт.

## 3. Закрывающий чек с кодами на минимальной сумме

Три заказа: одна пачка; один сет; смешанный (сет + пачка).

**Сделать.** Оплатить каждый, собрать по странице сборки, нажать «Собрано».
После вручения (или `scripts/api.sh orders/<N>/delivered`) чек уходит сам; если
нет — `scripts/api.sh orders/<N>/settlement-receipt`.

**Ожидаемо.** В ответе — номер чека и статус `pending`, через несколько минут
тик ставит `succeeded`. В чеке: у пачки — строка с количеством 1 и признаком
«ТМ», у сета — одна строка с кодом коробки, доставка — отдельной строкой;
сумма чека равна сумме оплаты до копейки, расчёт — «зачёт предоплаты».

**Где смотреть.** Кабинет ЮKassa → Платежи → платёж заказа → Чеки; письмо с
чеком на почту клиента; `orders.settlement_receipt_status`. Ответ ЮKassa с
ошибкой — в чате заказов («🚨 Заказ №N: ЮKassa отказала…»), текст ошибки
целиком — в ответе команды.

## 4. Статусы кодов в «Честном знаке» после чека

**Сделать.** Через сутки после `succeeded` найти коды заказов из п. 3 в личном
кабинете «Честного знака» (поиск по коду или по GTIN + серийному номеру).

**Ожидаемо.** Пачка и коробка сета — «Выбыл» (розничная продажа). Пачки внутри
проданного сета — по правилам набора (уточнить, что показывает кабинет).

**Где смотреть.** Личный кабинет «Честного знака» → Коды маркировки; у нас —
`order_marking_codes.status = 'sold'`.

## 5. Полный возврат

**Сделать.** По заказу из п. 3 (лучше смешанному) после `succeeded`:
`scripts/api.sh orders/<N>/refund-with-codes`.

**Ожидаемо.** В ответе — номер возврата, «кодов в чеке возврата» = числу
единиц. Деньги вернулись, клиенту — «Оформили возврат…», в чате заказов —
«↩️ Возврат» и «Коды маркировки ушли в чек возврата: N шт.». Чек возврата
прихода — с теми же строками и кодами, полный расчёт. Через сутки коды в
«Честном знаке» снова в обороте.

**Где смотреть.** Кабинет ЮKassa → платёж → Возвраты → чек возврата;
`order_marking_codes.status = 'returned'`, `refund_id`; кабинет «Честного
знака» — статус кодов. Отсканировать ту же пачку в новый заказ — должна
приняться с пометкой «код возвращался по заказу №N».

## 6. Расформирование набора и продажа пачки из него

**Сделать.** Продать набор целиком (п. 3), затем в другом заказе — только одну
пачку из такого же, ещё не проданного набора: собрать заказ по коду этой
пачки.

**Ожидаемо.** По ответу «Честного знака» (SR8968218) при продаже пачки из
набора через кассу набор расформировывается автоматически. Бот принимает код
пачки как обычной позиции, если у этой фасовки есть своя строка в таблице с
GTIN. Возврат одной пачки из **проданного** сета бот не делает: в чате заказов
— «🚨 частичный возврат по заказу с сетом», это `TODO(chz-partial-return)`.

**Где смотреть.** Кабинет «Честного знака» → набор (КИН) — статус
«расформирован», пачка — «Выбыл»; чат заказов.

## 7. Ошибочные сценарии

| Что сделать | Ожидаемо на странице сборки | Где ещё смотреть |
|---|---|---|
| Отсканировать пачку другого сорта | «Это не та пачка: в заказе «…», отсканировано «…»», счётчик не растёт | — |
| В заказе сет, отсканировать пачку из него | то же и «Пачки внутри сета не сканируются — нужен код на коробке» | — |
| Отсканировать ту же пачку второй раз | «Этот код уже отсканирован в этом заказе» | — |
| Отсканировать пачку, уже собранную в другой заказ | «Этот код уже в заказе №N» | `order_marking_codes` — одна строка |
| Лишняя пачка сверх количества | «По «…» уже отсканированы все N пачки — лишняя в коробке?» | — |
| Ввести вручную код без GS (`01…21…93xxxx`) | принят с пометкой «разделитель GS восстановлен» | `raw_code` с 0x1D |
| Ввести вручную обрывок кода | «Код не распознан, отсканируйте ещё раз.» | — |
| Ввести ссылку из QR | «Это QR-код со ссылкой…» | — |
| Позиция без GTIN в таблице | «Нет GTIN в каталоге», «Собрано» недоступна | `scripts/api.sh catalog/sheet` |
| Нажать «Собрано», не отсканировав всё | кнопка неактивна; через API — «Коды есть не на все позиции — …» | — |
